# Plasma-Proteomics-Stroke
Plasma Proteomics- Stroke subtypes
Statistical Analysis
We assessed the normality of the data using the Shapiro-Wilk test. If normally distributed, we summarize continuous variables as mean and standard deviation, else as median and interquartile range. We summarized categorical variables as number (percentage). We compared the baseline characteristics between the four groups using one-way ANOVA or Kruskal-Wallis test for continuous variables or Chi-square test for categorical variables. For pairwise comparisons, we used the T-test or Mann Whitney U test to compare the difference in means or medians, respectively, between the two groups. The protein relative abundance values were log2 transformed. 
Pairwise comparisons: We performed pairwise comparisons and identified the DEPs using three protein selection criteria: (i) ±1.5-fold change and unadjusted p-value <0.05 cut-offs (Welch’s t-test), (ii) confirmed selection in Boruta random forest-based feature selection (Boruta package in R version 4.3.2), and (iii) more than or equal to 20% variation explained by stroke subtypes in the variance partitioning analysis (VPA) (variancePartition package in R version 4.3.2). For all pairwise comparisons, we selected the top proteins that were commonly identified using two of the three protein selection approaches. We then conducted multivariable regularized logistic Least Absolute Shrinkage and Selection Operator (LASSO) regression analysis, adjusting the top proteins for age, sex, NIHSS, and GCS in the univariable pairwise analysis (rlassologit function in hdm R package version 4.3.2). We employed a regularized logistic regression method based on the double selection LASSO framework, to minimize model overfitting and adjust for relevant covariates by shrinking less informative predictors to zero. Prior to model fitting, collinearity among the these variables was assessed using variance inflation factors (VIF), and no concerning collinearity was observed. Adjusted p-values for the LASSO-selected predictors were then obtained using standard multivariable logistic regression. Additionally, we conducted the functional enrichment analysis using the Ingenuity Pathway Analysis software (QIAGEN Digital Insights, 2024) for all pairwise comparisons in the discovery cohort. We selected proteins with fold change ±1.2 and unadjusted p-value <0.05 and compared the enriched pathways between all pairwise comparisons using the z-score metric. The enriched pathways were identified using the following parameters: FDR corrected p-value<0.1 and z-score> 0.2. 
Multigroup comparisons: We utilized a supervised machine learning algorithm and performed feature selection by sparse partial least squares discriminant analysis (sPLS-DA) between the four stroke subtypes (mixOmics R package version 4.3.2). We performed 10-fold cross-validation repeated 50 times to tune the sPLS-DA model and select the number of components and proteins for classifying stroke subtypes.
Protein panels of stroke subtypes: From the top nominated proteins identified in pairwise and multigroup comparisons, we performed regularized LASSO logistic regression to select top classifiers and develop protein panels for classifying AIS, ICH, TIA, and MIM (rlassologit function in hdm R package version 4.3.2). The predictive performance of protein panels was evaluated using area under the receiver operating characteristic curves (AUC-ROC) via DeLong’s method. The diagnostic accuracy was assessed through sensitivity, specificity, positive predictive value (PPV), and negative predictive value (NPV), with 95% confidence intervals (CI) derived from 1,000 bootstrap resamples. 
Internal validation: To evaluate the performance and generalizability of protein panels, we applied repeated nested 10-fold cross-validation using LASSO logistic regression. Across 5 repetitions, models were trained on training folds and evaluated on test folds (total 50 outer folds). Predicted probabilities were pooled to compute the AUC and 95% CI using DeLong’s method and performance metrics were validated via 2000 bootstrap resamples. A final model was fit on the full dataset, and top protein classifiers were summarized by frequency across folds. Additionally, we validated protein expression patterns using BAK-270 targeted proteomics platform on the same samples, applying the same methodology of pairwise and multigroup comparisons. We determined the correlation of overlapping proteins between SomaScan and BAK-270 proteomics platform using Spearman rank correlation.
External validation: We externally validated protein expression patterns of the SomaScan hits using DIA-MS proteomics in an independent cohort. DIA-MS data were quantified using DIA-NN, log2 transformed, batch corrected using Combat function (sva package in R), imputed for ≤30% missing values from random distribution using Perseus, and normalized by total area sum. The validated hits were identified using p-value <0.05 and the discrimination ability was assessed using ROC curves.
